# Foundation Level — Batch 2

**IsDB Geoinformatics Data Platform (GEIDA) · Staff Certification Programme**

September–October 2026 · Hybrid: IsDB HQ Jeddah + Online

---

Batch 2 is the second cohort of the GEIDA Foundation Level Certification Training. It was delivered alongside the IsDB Operations Boot Camp while colleagues from the Regional Hubs were gathered at Headquarters, and runs in three parts.

!!! info "How Batch 2 is structured"
    **Part 1 — Preparatory.** Self-paced materials issued before the in-person day, covering the fundamentals and the tools. Available in [Resources](../resources/preparatory-batch-2.md).

    **Part 2 — In-person day.** A full day at IsDB HQ Jeddah on 10 September 2026, working with participants' own ongoing and pipeline projects. Certificates were presented at the close of the Boot Camp.

    **Part 3 — Online practical follow-up.** Three guided online sessions in which participants develop an applied GEIDA case using one of their own projects, concluding with a short case presentation.

## Tools used

All tools are web-based — no desktop software is required.

| Tool | Purpose |
|---|---|
| [eToolkit](https://etoolkit.terrawatch.net) | Automated EO report generation for a project area |
| [Google Earth Web](https://earth.google.com/web) | Digitising project locations, KML export |
| [GeoLibre](https://viewer.geolibre.app) | Web-based spatial analysis, boundaries, buffers |
| [GADM](https://gadm.org) | Administrative boundaries by country |

!!! note "eToolkit access"
    Batch 2 participants should continue to use the eToolkit credentials issued to them before the in-person day. If you no longer have them, contact the GEIDA Programme team.

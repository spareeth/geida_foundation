## Learning objectives

By the end of the in-person day, participants are able to:

1. Explain why spatially referenced evidence strengthens project preparation, supervision and reporting
2. Distinguish the main types of satellite data and describe the limitations of each
3. Identify vector and raster data types, and explain spatial, temporal and spectral resolution in practical terms
4. Digitise a project location in Google Earth and export it for use in other tools
5. Download an administrative boundary and perform a basic spatial operation without desktop GIS software
6. Generate an automated EO analysis report in the eToolkit for their own project area

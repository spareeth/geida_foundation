# Foundation Level — Batch 1

**IsDB Geoinformatics Data Platform (GEIDA) · Staff Certification Programme**

6–9 July 2026 · Hybrid: IsDB HQ Jeddah + Online

---

Batch 1 was the first cohort of the GEIDA Foundation Level Certification Training — four days covering Earth Observation fundamentals through to case-study presentations. This section contains all session recordings, slide decks, exercises and reference materials from those four days.

!!! info "How to use this section"
    - Follow the [Training Agenda](../agenda.md) for the full programme overview.
    - Navigate day by day using the sidebar — each day has a morning and afternoon page.
    - Each session page contains the **recording**, **slide decks**, **key concepts** and **exercise instructions**.
